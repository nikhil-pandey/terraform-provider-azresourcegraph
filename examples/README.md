# Examples

This directory contains examples used for generated documentation and manual Terraform CLI testing.

The documentation generator looks for files in the following locations. Other Terraform files are ignored, which allows additional runnable fixtures without including them in Registry documentation.

- `provider/provider.tf`: provider index example
- `data-sources/<data-source-name>/data-source.tf`: data source example
- `resources/<resource-name>/resource.tf`: resource example
